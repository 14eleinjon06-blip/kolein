# Five-Minute Presentation Guide — Computer Registration System

**Important:** This is a suggested script. If the instructor prohibits voice-over, use it as live presentation notes instead. Do not claim that testing or deployment is complete until you have performed and verified it.

## 0:00–0:35 — Introduction
“Good day. Our project is the Computer Registration System for Nueva Vizcaya State University, Bayombong Campus. The project focuses on organizing computer laboratory registration and monitoring. Manual records can be difficult to organize and review, so we are exploring a web-based way to record laboratory visits.”

## 0:35–1:05 — Purpose
“The prototype aims to collect laboratory visit details in one form and display the entries in an organized list. The final requirements should be confirmed with the intended users.”

## 1:05–1:40 — SDLC
“Our proposed SDLC model is Waterfall. Phase 1 is planning and requirements analysis. Phase 2 is system design. Phase 3 is implementation. Phase 4 is testing and deployment. Phase 5 is maintenance. We will update this documentation based on the actual work completed.”

## 1:40–2:00 — Technology stack
“The prototype uses HTML for structure, CSS for the design, and JavaScript for interactions. It stores demonstration records in the current browser using localStorage. GitHub stores the project files and tracks changes.”

## 2:00–4:25 — Live demo sequence
1. Open `index.html` in a browser.
2. Show the Dashboard and explain the count cards.
3. Select **Register a Visit**.
4. Enter fictional sample details and submit.
5. Open **Registration Records** and find the new entry.
6. Search for the entry and change its status.
7. Return to Dashboard to show updated counts.
8. Click **Export CSV** to demonstrate the export feature.

Use fictional information only.

## 4:25–5:00 — Limitations and conclusion
“This is a front-end prototype. Its records are stored only in the current browser, so it is not a centralized or secure university system. A future version would need a backend database, secure login, and approved access permissions. Thank you.”
