# Computer Registration System

A beginner-friendly web prototype for organizing computer laboratory visit registrations at Nueva Vizcaya State University (NVSU), Bayombong Campus.

## Problem
Manual registration can make records harder to organize and review. This prototype demonstrates a form and a records page for viewing and managing demo registrations.

## Features
- Dashboard counts for all, pending, and approved entries
- Registration form
- Search and status filtering
- Update status to Pending, Approved, or Rejected
- Delete demo entries
- Export records to CSV
- Responsive layout

## Technology stack
- HTML5 — page structure
- CSS3 — styling
- JavaScript — interactions
- Browser localStorage — demo-only storage in the current browser
- GitHub — source control

## Run
Download or clone the repository and open `index.html` in a modern browser. You can also use VS Code Live Server.

## Important limitations
This is a front-end prototype, not a production university system. Data is stored only in the browser where it was entered. It has no secure login, shared database, server-side validation, or role-based permissions. Use fictional data only. Room names and times are examples and should be confirmed with the school.
